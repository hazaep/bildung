La Escuela 5 me parece uno de los rediseños más importantes de todo el mapa.

Porque aquí Bildung deja de preguntarse:

```
¿Cómo construyo algo?
```

Y empieza a preguntarse:

```
¿Cómo hago que siga existiendo?
```

Esa es una diferencia enorme.

Hasta la Escuela 4, Bildung es principalmente una extensión de Hazael.

A partir de la Escuela 5, Bildung intenta convertirse en una entidad capaz de conservar conocimiento, propósito y capacidad más allá de su creador.

```

```

# Bildung Organizational OS

Capaz de coordinar:

```
PersonasProcesosConocimientoAgentesCapital
```

sin requerir supervisión constante.

---

Y creo que esta escuela tiene una frase que resume perfectamente su propósito:

```
Escuela 1:Aprender a ver.Escuela 2:Aprender a construir.Escuela 3:Aprender a aprender.Escuela 4:Aprender a decidir.Escuela 5:Aprender a desaparecer.
```

Porque una organización verdaderamente madura no demuestra su fortaleza cuando el fundador está presente.

La demuestra cuando el fundador no está y aun así el sistema continúa evolucionando.
