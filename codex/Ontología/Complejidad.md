# Complejidad

## Definición operativa

La complejidad es la propiedad de un [[Sistema]] donde el comportamiento del todo **no es predecible a partir del conocimiento perfecto de sus partes**. Surge cuando múltiples elementos interactúan mediante reglas simples pero generan patrones globales no lineales, adaptativos y frecuentemente irreversibles.

No es sinónimo de "complicado". Un motor de relojería es complicado (muchas partes, pero predecible). Un ecosistema es complejo (pocas reglas, pero impredecible).

## Pregunta clave

> ¿Qué aparece cuando múltiples elementos interactúan?

## Propiedades de los sistemas complejos

- **Auto-organización**: el orden emerge sin un controlador central
- **No linealidad**: la salida no es proporcional a la entrada. Ver [[Apalancamiento]].
- **Adaptación**: los agentes modifican su comportamiento en respuesta al entorno
- **Sensibilidad a condiciones iniciales** (efecto mariposa): pequeñas diferencias producen trayectorias radicalmente distintas
- **Emergencia**: el todo excede la suma de las partes. Ver [[Emergencia]].
- **Irreversibilidad**: no se puede "deshacer" el sistema a su estado anterior

## Implicación operativa

Cuando un sistema es complejo, **no se puede controlar**. Se puede:

1. **Diseñar condiciones iniciales** (en lugar de dictar resultados)
2. **Modificar restricciones** (en lugar de microgestionar)
3. **Observar patrones emergentes** (en lugar de predecir con precisión)
4. **Intervenir en puntos de [[Apalancamiento]]** (en lugar de aplicar fuerza uniforme)

Esto es fundamental para la [[Gobernanza Adaptativa]] y el diseño del [[Laboratorio Bildung]].

## Dominios de aplicación

| Dominio | Manifestación |
|---|---|
| Ecosistemas naturales | Poblaciones, depredadores, clima |
| Mercados financieros | Precios, burbujas, pánicos |
| Organizaciones | Cultura, innovación, resistencia al cambio |
| Cognición | Aprendizaje, creatividad, sesgos |
| Software distribuido | Sistemas multi-agente, redes, blockchain |

## Anti-patrón

**Ilusión de control**: tratar un sistema complejo como si fuera complicado. Imponer jerarquías rígidas, planes detallados a largo plazo, o KPIs lineales sobre sistemas que operan en el borde del caos.

## Relaciones
